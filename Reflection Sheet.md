This project is called Priority Task Sorter.

Its main purpose is to sort a messy list of tasks into ranked priorities.

I start by asking the user for their tasks (just a task dump).
Then I show the tasks to the user and ask them for the priorities, they input them one at a time.

Then, the program checks each input for validity and sorts the task by rankings.

I use lists/dictionaries, 'lambda' and the 'sorted' function.

The output shows the new list to the user.

I tested the program by inputting a task dump and then ranking them like a user would.

One problem I solved was the output only showing the newest task (the dictionary kept overwriting itself).

What I learned from this project is 'lambda' and the 'sorted' function.

If I continued this project, I could make sure to verify rankings to avoid duplicates and add in factors like time and urgency.
